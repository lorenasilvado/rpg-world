# M0 — Fundação e spike

Escrito pelo `/planejar M0` quando este milestone é o próximo. É plano, não comportamento: os
ACs vivem nas specs das features (`AC-F<n>-NN`) e aqui só são referenciados. Quando o milestone
encerra, o `/fechar` fecha o milestone no GitHub e o PR do próximo `/planejar M<n+1>` marca este
doc como histórico (`status: encerrado`); depois disso ele não é mais atualizado.

## Escopo final

O M0 não entrega feature (`F#`). Entram:

- Setup do projeto na stack do [ADR 0001](../adr/0001-stack-da-v1.md) (#1).
- Layout vazio do editor, responsivo, nos tokens do design system (#5).
- Publicação no GitHub Pages ([ADR 0002](../adr/0002-hospedagem-github-pages.md)) (#6).

  - **determinismo:** mesmo hash do terreno no Chrome, Firefox e WebKit (#8);
  - **desempenho:** geração no worker (#9) e 5.000 sprites no PixiJS (#10).

## Critério de saída testável

**go/no-go**, decidido pelo usuário no `/fechar` do M0. Para dar go:

1. `npm run dev`, `lint` e `test` passam, e o CI roda lint e testes (#1).
2. O layout vazio responde abaixo de 768 px (#5).
3. O usuário aprova o mockup como referência visual da v1, com paleta e spritesheet inicial
   definidos (#7).
4. O teste de hash passa nos 3 navegadores (#8).
5. As metas de tempo (prévia ≤ 150 ms, 1024² ≤ 1,5 s) e de fps (≥ 55 com 5.000 sprites) são
   atingidas (#9, #10). A meta de fps só foi medida em GPU dedicada (RX 7600), e 2 de 6 medições
   logo depois de abrir o Chrome ficaram abaixo dela (52 e 1 fps). A medição em GPU integrada
   está pendente na #38.

Se algum item falhar, o no-go fica registrado com o motivo, e o caminho alternativo vira um ADR
novo antes do M1.

## Riscos

| Risco | Mitigação |
|---|---|
| Ícones CC0 não chegam ao estilo medieval do design system | O spike visual mostra cedo; trocar a arte depois, com o spritesheet isolado em `render/style` |
| `simplex-noise` ou `alea` usam funções Math que variam entre engines | O spike de determinismo testa nos 3 motores; se falhar, implementar o ruído no próprio núcleo |
| PixiJS abaixo de 55 fps com 5.000 sprites em GPU integrada | Medir no spike; culling e nível de detalhe entram no M1 |
